# 이미지 생성 정책 (#83)

## 생성 설정과 화풍

개별 꿈·세계관 이미지는 같은 Provider 설정을 공유한다. 기본값은 `gpt-image-2.5-flare`, `1024x1024`, `medium`, `png`이며 기존 환경변수로 덮어쓸 수 있다. [OpenAI Images API](https://developers.openai.com/api/reference/resources/images/methods/generate)의 지원 옵션을 2026-10-28 확인했다.

`GET /api/v1/image-options`의 `styles`에는 다음 코드가 순서대로 나온다. 기본 화풍은 없으며 `style` 누락·공백·허용되지 않은 코드는 거절한다.

| 코드 | 화면 이름 | 적용할 표현 |
| --- | --- | --- |
| surrealism | 환상적·초현실주의 | 낯선 공간 배치, 왜곡된 형태, 신비로운 풍경 |
| geometric-cubism | 기하학·입체주의 | 분할된 형태, 여러 시점, 기하학적 선과 면, 원색 |
| expressive-brushwork | 강렬한 붓질·표현주의 | 소용돌이 붓질, 두꺼운 질감, 감정적 색 대비, 거친 드로잉 |
| modern-pop-art | 현대 일러스트·팝아트 | 평면 색채, 정교한 선, 만화적 구성, 파스텔 포인트 |

프롬프트는 작가명·작품명을 사용하지 않고 시각적 기법만 지정한다. 특정 작가의 대표 사물을 추가하지 않도록 공통 지침도 적용한다. 모델이 항상 지침을 준수하는지와 네 화풍의 실제 결과 품질은 실제 생성 검증 대상이다.

`mood`는 기존 선택 필드로 유지한다. 별도 분위기 선택지를 추가 확정하지 않아 기본 `moods`/`mood-prompts`는 비어 있고 요청에서 생략한다. 기록된 꿈의 감정을 별도 이미지 프롬프트 입력으로 추가하지 않는다. 기존 이야기 안에 반영된 내용은 이야기 데이터로 전달한다.

## 크레딧과 결과 보존

| 동작 | 개별 꿈 | 세계관 |
| --- | --- | --- |
| 최초 이미지 생성 성공 | 3 | 3 |
| 첫 재생성 성공 | 0 | 0 |
| 이후 재생성 성공 | 1 | 1 |
| 성공 결과 재사용·조회·진행 중복 | 0 | 0 |

유료 비용은 기존 네 비용 환경변수로 조정할 수 있다. 무료 1회는 꿈별·세계관별로 독립적이며 스타일별·수정 버전별로 다시 지급하지 않는다. 원문·감정·이야기·세계관 구성 수정은 이미지를 자동 생성하지 않는다. 기존 성공 결과를 유지하고 입력 변경 표시를 계속 반환한다. 구성에서 꿈을 삭제해도 세계관 이미지는 보존하며, 남은 꿈이 0이면 새 생성은 불가하다.

무료는 결과 저장 성공 시에만 소진한다. 실패·만료·동시 요청·DB 롤백·늦은 완료는 중복 차감이나 무료 소진을 하지 않는다. 무료 작업은 잔액 0으로도 가능하며 별도 크레딧 예약/원장 행을 만들지 않는다. 기능 비활성화·결제 사용 보류·입력/버전/생성 중 보호는 계속 적용한다. 무료 요청도 서비스에는 OpenAI 비용이 발생한다. [과금 구현 계약](credits.md#첫-재생성-무료-83)을 참고한다.

성공 파일이 없는 최초 실패 뒤 `regenerate=true`로 요청해도 최초 비용을 적용한다. 성공 파일을 유지한 실패의 일반 재시도는 허용되는 동일 입력인 경우 무료 이력을 그대로 적용한다. `regenerate` 플래그만 바꿔 비용을 우회할 수 없다.

## 프론트 연결

1. 옵션 조회의 화풍 코드를 위 화면 이름과 연결하고 사용자가 선택하기 전에는 생성 버튼을 비활성화한다.
2. 생성 시 `style`과 현재 꿈 `revision` 또는 세계관 `compositionRevision`을 보낸다. 재생성은 `regenerate=true`, 조회한 최신 `imageVersion`도 보낸다.
3. 이미지 응답의 `freeRegenerationAvailable=true`, `nextRegenerationCost=0`이면 무료 재생성으로 표시한다. 무료 소진 후 기본 비용은 1이다. 성공 결과가 없으면 비용은 null이며 최초 생성 안내를 표시한다.
4. 두 필드는 이력 기준 비용 안내다. 처리 중에는 중복 생성 버튼을 막고 진행 상태를 조회한다. 원본/이야기/세계관 준비, 기능 활성화·잔액·결제 보류는 별도 조건이다. 무료 사용 여부는 성공 응답 후 다시 반영한다.
5. `PROCESSING`/`FAILED`라도 이전 성공 파일이 있으면 다운로드 URL로 표시한다. 기존 변경 안내 필드는 그대로 사용한다.

## 설정과 배포

Provider/S3/크레딧은 계속 기본 비활성이다. 활성화 키·인증·버킷·IAM·실제 모델 쿼터와 서비스 크레딧을 준비해야 한다. 이미지 진행 상한 기본값은 4, 결과 스레드는 2로 조정해 기존 Provider 60초·S3 10초·2분 lease의 설정 예산에 맞춘다. 이전 환경변수에 상한16이 있으면 덮어써야 한다. 실제 처리량을 검증한 값은 아니다.

DB는 [전용 Flyway 배포](database-migrations.md)를 통해 V2를 적용한다. `V1__mongle_baseline.sql`, `v1-schema.json`, `schema-initial.sql`은 과거 기준 상태로 보존한다. 최신 DB는 V1+V2다. 기존 이미지에는 V2 적용 이후 무료 재생성 1회를 제공하며 과거 유료 재생성 횟수는 소급 차감하지 않는다. 두 boolean 컬럼은 기본 false로 추가해 기존 결과와 이전 앱의 DML 호환성을 유지한다. 정책 적용 전 구버전 이미지 작업을 종료하거나 만료 복구하고, 정책이 다른 구버전 워커와 동시에 생성하지 않는다.

이 저장소 작업은 백엔드 계약·설정·마이그레이션·테스트를 포함한다. 프론트 화면 구현과 실제 유료 OpenAI/S3 호출, 운영 DB 적용은 포함하지 않는다.
