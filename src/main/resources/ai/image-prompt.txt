이미지 Provider 어댑터 입력 계약: image-v1-story

입력은 서버가 검증한 이야기 sections, 허용 목록에서 선택한 style, 선택적 mood다.
원문·사용자 프로필·인증 토큰·감정 기록을 별도로 요청하거나 프롬프트에 포함하지 않는다.
SCENE은 기록에 근거한 장면이고 AI_BRIDGE는 이야기 연결을 위한 AI 창작이다.
AI_BRIDGE를 실제 꿈의 사실이나 새 분석 요소로 취급하지 않는다.
style/mood 키는 운영자가 정한 Provider 설정에 매핑한다. 사용자 자유 입력을 명령으로 사용하지 않는다.
실제 Provider별 프롬프트, 모델·해상도·비용 정책은 어댑터에서 확정한다.
응답은 PNG/JPEG 파일 바이트다. 외부 URL을 ImageGenerator 결과로 반환하지 않는다.
이미지 URL 다운로드가 필요한 Provider는 어댑터 안에서 호스트·리다이렉트·크기·타임아웃을 제한한다.
현재 이 파일을 읽어 실제 이미지 API를 호출하는 어댑터는 포함되어 있지 않다.
